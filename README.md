# COM Logger - Qt6 Application

Приложение для логирования данных из COM-порта с разбивкой на пакеты по паузе.

## Требования

- **Qt 6.9.3** (или совместимая версия Qt6)
- **MSVC 2022** (для Windows)
- **Qt Serial Port** модуль

## Сборка в Windows

### Вариант 1: Через командную строку Qt

1. Откройте **Qt 6.9.3 Command Prompt** (или выполните `qtenv6.bat`)
2. Перейдите в директорию проекта
3. Создайте папку для сборки и выполните сборку:

```cmd
mkdir build\debug
cd build\debug
qmake ..\..\comlogger.pro -spec win32-msvc CONFIG+=debug
nmake
```

Для release версии:
```cmd
mkdir build\release
cd build\release
qmake ..\..\comlogger.pro -spec win32-msvc CONFIG+=release
nmake
```

### Вариант 2: Через VSCode

1. Откройте проект в VSCode
2. Убедитесь, что Qt добавлен в PATH или настроен terminal profile
3. Нажмите `Ctrl+Shift+B` для сборки (выберите "Build All Debug" или "Build All Release")
4. Для запуска нажмите `F5` (отладка) или `Ctrl+F5` (без отладки)

## Использование

1. Запустите приложение
2. Настройте параметры COM-порта:
   - Номер порта
   - Скорость (9600-115200 бод)
   - Разрядность (5-8 бит)
   - Чётность (None, Even, Odd, Space, Mark)
   - Стоп-биты (1, 1.5, 2)
3. Настройте разбиение на пакеты:
   - По длительности паузы (мс)
   - Или по количеству символов
4. При необходимости включите CRC-16 Modbus контроль
5. Нажмите кнопку **Старт** для начала записи
6. Файл лога будет создан в формате: `com_log_YYYY-MM-DD_HH-mm-ss.txt`

## Особенности

- **Разбиение на пакеты**: по паузе между байтами
- **CRC контроль**: опциональный CRC-16 Modbus
- **Автосохранение**: все настройки сохраняются в реестр/INI файл
- **Статистика**: подсчёт пакетов по преамбуле и длине
- **Визуализация**: подсветка новых пакетов в таблице статистики
- **Логирование**: запись всех пакетов в hex-формате
