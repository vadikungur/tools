# COM Port Logger - Приложение для логирования данных из COM-порта

Приложение на Qt6 для получения, разделения на пакеты и логирования данных из COM-порта.

## Возможности

1. **Разбиение на пакеты по паузе между байтами**
   - По длительности (в миллисекундах)
   - По длине символа (количество символов)

2. **Контроль целостности пакетов CRC-16 Modbus**
   - Опциональная проверка CRC через настройки
   - Автоматическая валидация полученных пакетов

3. **Настройка параметров COM-порта**
   - Выбор порта
   - Скорость передачи (9600 - 115200 бод)
   - Разрядность данных (5-8 бит)
   - Биты чётности (Нет, Чётный, Нечётный, Маркер, Пробел)
   - Стоп-биты (1, 1.5, 2)

4. **Автоматическое сохранение настроек**
   - Все параметры сохраняются между запусками
   - Используются QSettings для хранения конфигурации

5. **Управление логированием**
   - Кнопка Старт/Стоп
   - Изменение цвета кнопки (зелёный - готов, красный - идёт запись)

6. **Сохранение данных в файл**
   - Hex-формат с пробелами между байтами
   - Имя файла содержит дату и время начала записи
   - Формат: `com_log_YYYY-MM-DD_HH-mm-ss.txt`

7. **Вкладка "Статистика"**
   - Табличное отображение статистики пакетов
   - Группировка по преамбуле (первые 2 байта) и длине пакета
   - Подсчёт количества полученных пакетов каждого типа
   - Автоматическая подсветка жёлтым цветом (0.2 сек) при поступлении новых пакетов

8. **Вкладка "Пакеты"**
   - Построчное отображение принятых пакетов
   - Время получения и hex-представление пакета

9. **Строка состояния**
   - Отображение всех действий приложения
   - Временные метки событий

## Сборка

### Требования
- Qt 6.4 или выше
- Модуль Qt SerialPort
- Компилятор C++17

### Процесс сборки

```bash
# Установка зависимостей (Debian/Ubuntu)
sudo apt-get install qt6-base-dev libqt6serialport6-dev

# Сборка проекта
qmake6 comlogger.pro
make

# Запуск приложения
./comlogger
```

## Использование

1. **Настройка подключения**
   - Выберите COM-порт из списка
   - Настройте скорость, разрядность, чётность и стоп-биты
   - Выберите тип паузы для разбиения на пакеты:
     - "По длительности (мс)" - пауза в миллисекундах
     - "По длине символа" - пауза в количестве символов
   - Установите значение паузы
   - При необходимости включите контроль CRC-16 Modbus

2. **Запуск логирования**
   - Нажмите кнопку "Старт" (зелёная)
   - Кнопка изменится на "Стоп" (красная)
   - Начнётся приём данных и запись в файл

3. **Просмотр данных**
   - Вкладка "Статистика" - подсчёт пакетов по типам
   - Вкладка "Пакеты" - подробный список всех пакетов

4. **Остановка логирования**
   - Нажмите кнопку "Стоп"
   - Данные будут сохранены в файл
   - Параметры автоматически сохранятся для следующего запуска

## Формат файлов

### Файл лога (com_log_*.txt)
```
01 02 03 04 05
10 20 30 40 50 60 70 80
FF FE FD FC
```

Каждая строка содержит один пакет в hex-формате с пробелами между байтами.

## CRC-16 Modbus

При включённой опции контроля CRC:
- Последние 2 байта пакета интерпретируются как CRC
- CRC проверяется по алгоритму Modbus (полином 0xA001)
- Пакеты с ошибкой CRC логируются, но выводится предупреждение
